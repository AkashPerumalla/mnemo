# Mnemo

A personal AI whose memory is a file you own, running on NVIDIA Nemotron via
Nebius Token Factory. Source: https://github.com/AkashPerumalla/mnemo

This public Space runs in demo mode: each visitor gets their own memory space
keyed to a browser cookie, with a per-visitor message cap. Clone the repo and
run it with your own Nebius key for unlimited, fully private use.
